# Employee Onboarding Guide

## First Week
- Day 1: HR orientation, setup accounts, get equipment
- Day 2: Team introduction, setup development environment
- Day 3: Code walkthrough, review coding standards
- Day 4: Pair programming with mentor
- Day 5: First small task assignment

## First Month
- Complete training modules
- Attend team standups
- Submit first code review
- Learn company tools and processes
- Meet with cross-functional teams

## Required Tools
- Slack for communication
- GitHub for code
- Jira for project management
- Confluence for documentation
- Ollama for local AI development
